# 💰 Dashboard de Finanças Pessoais

Projeto de portfólio desenvolvido com **HTML, CSS e JavaScript puro**.

A aplicação permite registrar receitas e despesas, acompanhar o saldo e filtrar as transações. Os dados ficam salvos no navegador usando `localStorage`.

## ✨ Funcionalidades

- Adicionar receitas e despesas
- Categorizar transações
- Calcular saldo automaticamente
- Filtrar por receita ou despesa
- Excluir transações
- Limpar todos os dados
- Persistência com `localStorage`
- Layout responsivo
- Interface sem frameworks

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage API

## 🚀 Como executar

Não é necessário instalar dependências.

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Para uma experiência melhor durante o desenvolvimento, você pode usar a extensão **Live Server** do VS Code.
